# OCT-LOFT 3D Venue Map / OCT-LOFT 3D 场地地图

Interactive 3D map of OCT-LOFT Creative Culture Park (华侨城创意文化园), Nanshan, Shenzhen: numbered buildings, the C2 main venue, nearby roads, metro and bus stops, walking directions to C2, saved views, Chinese / English.

**Preview:** https://polluxchou.github.io/oct-loft-map/

- Single self-contained page (`index.html`); three.js 0.160.0 is loaded from unpkg.
- Indicative only, not a survey. Building heights are mostly estimates; sources are shown in each building's details.

## Data and licence

- Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the Open Database License (ODbL). The derived data embedded in `index.html` is likewise made available under the ODbL.
